# House Price Prediction using Machine Learning

## Overview

This project predicts residential house prices using machine learning models on the Ames Housing Dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Project Workflow

1. Data Cleaning
2. Missing Value Handling
3. Exploratory Data Analysis (EDA)
4. Feature Encoding
5. Model Training
6. Hyperparameter Tuning
7. Kaggle Submission

## Models Used

### Linear Regression
- R² Score: 0.872

### Random Forest Regressor
- R² Score: 0.894

## Kaggle Result

- Public Score (RMSLE): **0.15236**

## Features

- One-Hot Encoding
- ColumnTransformer Pipeline
- GridSearchCV Hyperparameter Tuning
- Automated Prediction Pipeline
